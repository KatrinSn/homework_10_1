# Домашняя работа 10_1
***
## Описание проекта
 _Проект, который содержит несколько виджетов по обработке данных клиентов банка_ 
1. Маскировка конфеденциальных данных
2. Маскировка данных с учетом типа карты или счета.
3. маскировка аккаунта пользователя
4. вывод даты операции в пользовательском формате
5. фильтр только выполненных операций
6. сортировка операций по дате (по убыванию)
***
### Цель проекта

 _Ускорить работу по обработке данных клиентов и проведенных банковских операциий_ 

***
#### Инструкция по использованию
 _Для использования_ 
1. Клонирование репозитория по SSH ключу 
```bash
git clone [git@github.com:KatrinSn/homework_10_1.git]
cd [homework_10_1]
```
2. в описании проекта выбрать необходимую операцию
3. запустить пакет main.py
4. указать номер выбранной функции
5. ввести данные для обработки
